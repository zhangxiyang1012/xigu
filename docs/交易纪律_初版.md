# 析股：买入与卖出纪律（初版）

> 来源：本目录 8 份 PDF，共 54 页；其中 2026-07-28、2026-07-30 各有一组内容重复版本，归纳时已去重。
> 本文把课程观点改写为可执行、可回测的规则，不沿用资料中的具体日期、指数点位或当时热点。

## 一、总决策链

市场环境 → 主线板块 → 核心个股 → 量价结构 → 拐点确认 → 风险退出

任何一层不满足，就不进入下一层。单一指标（底背离、均线、缩量、涨停等）不能独立构成买入理由。

## 二、统一判定口径

1. 所有日线信号原则上以收盘数据确认，盘中信号只用于预警。
2. MA5、MA10判断短期节奏，MA20作为中短期生命线。
3. “放量”初版定义为成交量 ≥ 近5日均量的1.2倍；“缩量”定义为成交量 ≤ 近20日均量的70%。具体阈值需回测优化。
4. “有效跌破”满足以下任一条件：
   - 收盘跌破预设防守位；
   - 放量收盘跌破MA20或关键平台；
   - 普通缩量跌破MA20后，下一交易日仍未收回。
5. 涨停、跌停沿用现有系统口径：日涨跌幅绝对值 > 9.8%。
6. 5-10个交易日是节奏观察窗口，不是机械预测；到达窗口后提高警惕，不直接反向交易。

## 三、买入纪律

### B0：基础排除

出现任一情形，不开新仓：

- ST、退市整理、长期停牌；
- 上市不足120个交易日（专门的次新策略除外）；
- 近20日平均成交额低于1亿元；
- 连续一字涨停、无法正常成交；
- 已放量跌破关键平台且没有止跌结构；
- 所属行业处于明确退潮或系统性下降阶段；
- 市场核心股批量破位，指数与核心股出现明显背离。

### B1：市场环境门槛

允许开仓至少满足：

- 市场不处于系统性风险状态；
- 主线核心股没有批量跌破MA20或关键平台；
- 焦点股 → 热点板块 → 市场情绪的风险传导没有形成；
- 若市场处于大级别下降期，只允许小仓位反弹策略，不使用趋势仓位。

市场风险状态下：停止普通买入，只管理存量仓位。

### B2：行业门槛

原则上只做行业综合强度前3名。行业评分建议由以下部分构成：

- 20日行业涨幅排名：30%；
- 成分股站上MA20比例：25%；
- 行业成交额增速：20%；
- 涨停及强势股数量：15%；
- 龙头相对强度：10%。

行业必须同时满足：

- 趋势未明确转弱；
- 成分股有一定广度，不是单只股票孤立上涨；
- 龙头强于行业指数和多数同行；
- 回调时量能收缩，资金没有明显撤离。

### B3：核心个股门槛

优先选择：

- 行业成交额、涨幅或市值靠前的核心股；
- 过去20日相对行业指数表现靠前；
- MA20向上且收盘位于MA20上方；
- MA5 ≥ MA10 ≥ MA20，或MA5刚向上穿越MA10；
- 上涨阶段量价平稳，回调阶段明显缩量。

普通跟风股不得使用“龙头深跌反弹”模型。

### B4-A：主线强势股缩量回调

必须全部满足：

1. 此前处于明确上升趋势；
2. 回调持续2-5个交易日；
3. 回调量能逐步缩小；
4. 最新成交量低于20日均量的70%；
5. K线实体较小，单日振幅不超过5%；
6. 未有效跌破MA20；
7. 低点靠近MA10、MA20或前期突破平台；
8. 行业趋势没有同步转弱。

以上条件只代表“进入观察池”，不能直接买入。

买入确认至少满足以下两项，且不能出现明显长上影：

- 收盘重新站上MA5；
- 收盘突破前一交易日最高价；
- 成交量达到前5日均量的1.1-1.5倍；
- 行业指数和行业龙头同步转强。

### B4-B：主线龙头深跌修复

这是激进策略，单只仓位上限减半。必须满足：

- 是经过历史行情验证的行业核心股；
- 距近期高点回撤15%-30%；
- 出现底背离、止跌小K线或连续缩量；
- 行业未进入系统性下降趋势；
- 重新站上MA5且量能恢复。

若仍位于MA20下方，只能定义为反弹交易，不能定义为趋势反转。

### B4-C：活跃股二次参与

活跃股观察池准入：

- 近期出现过可成交的放量涨停，缩量一字板不计；或
- 连续2根以上涨幅超过4%的放量中长阳。

不追首次上涨末端。二次参与必须等待：

- 回调不跌破首次涨停起点或预设防守位；
- 调整约5-10个交易日且总体缩量；
- 出现W底、双底、关键均线支撑或类似止跌结构；
- 回踩确认支撑后再次转强。

### B5：禁止追高

- 上涨已持续5-10个交易日，不因强势而盲目追入；
- 反弹进入周期后段并出现放量，优先视为风险信号；
- 破位后的反弹若未收复破位点，只是风险释放窗口，不是买点；
- 高位巨量、放量滞涨、长上影时禁止开新仓。

### B6：仓位纪律

单只股票股数 = 账户允许亏损金额 ÷（买入价 - 止损价）

- 单笔允许亏损：总资金的0.5%-1%；
- 单只股票仓位：不超过总资金15%；
- 激进深跌反弹：单只不超过8%；
- 单一行业总仓位：不超过35%；
- 同时持有4-8只股票；
- 同一行业多只股票按一个风险因子合并计算，不能视为真正分散。

下单前必须先写出防守位；无法定义防守位，不允许买入。

## 四、卖出纪律

### S0：硬止损

出现任一条件执行退出：

- 收盘跌破买入依据对应的防守位：立即退出；
- 放量跌破MA20或关键平台：原则上全部退出；
- 普通缩量跌破MA20，下一交易日仍不能收回：退出；
- 浮亏达到1-1.5倍ATR：退出；
- 活跃股跌破预设防守位：本次交易判定失败，立即离场，不补仓摊低成本。

### S1：趋势减仓与退出

- 放量跌破MA10：先减仓一半；
- 放量跌破MA20：原则上清仓；
- 反弹无量并再次跌破前低：清仓；
- 破位后反弹未收复破位点：利用反弹退出，不把反弹当反转；
- 强势股以MA5作为短期防守位时，跌破后按计划减仓，不临时修改规则。

### S2：行业与市场退出

- 所属行业跌出强度前3名并连续3天走弱：减仓或退出；
- 多只板块核心股同时破位：提前降低该行业全部持仓；
- 焦点股走弱向板块和市场情绪扩散：停止开仓并加速退出弱仓；
- 指数仍强但核心股普遍转弱：按核心股信号处理，不等待指数确认。

### S3：止盈

- 盈利达到8%-12%：先兑现约1/3；
- 剩余仓位沿MA5或MA10移动止盈；
- 连续上涨5-10个交易日后出现放量：主动降低仓位；
- 高位放量滞涨、异常巨量、长上影或顶背离：分批退出；
- 超短游资型活跃股出现放量阶段，优先按短期高点风险处理。

### S4：时间止损

- 买入后超过10个交易日仍未走强：降低预期，减仓或退出；
- 预期中的次日/随后转强没有出现：取消交易逻辑，不无限等待；
- 弱股在反弹窗口内仍不能出现长阳或涨停：弃弱换强，但不能追逐已经运行到周期末端的强股。

## 五、买卖纪律优先级

从高到低：

1. 预设防守位与账户风险上限；
2. 市场及行业系统性风险；
3. 放量破位；
4. MA20趋势状态；
5. 量价异常、顶底背离；
6. 5-10日节奏与时间止损；
7. 盈利目标。

低优先级信号不能否定高优先级风险。例如：出现底背离，但行业核心股批量破位，仍不允许买入。

## 六、建议在析股应用中生成的纪律信号

### 买入观察标签

- 主线行业前3；
- 行业MA20广度健康；
- 核心股/相对行业强势；
- 多头排列；
- 站上MA20；
- 缩量回调2-5天；
- 关键支撑附近；
- 小K线止跌；
- 重新站上MA5；
- 突破前一日最高价；
- 放量转强；
- 活跃股二次启动候选。

### 禁买或降权标签

- 市场风险；
- 行业退潮；
- 核心股批量破位；
- 放量跌破MA20；
- 放量跌破平台；
- 高位放量滞涨；
- 长上影异常量；
- 顶背离；
- 反弹无量；
- 上涨周期后段；
- 无法定义防守位。

### 卖出预警标签

- 跌破预设防守位；
- 放量跌破MA10（减半）；
- 放量跌破MA20（退出）；
- MA20次日未收回；
- 行业连续3天走弱；
- 板块核心股批量破位；
- 盈利达到首档止盈；
- 移动止盈触发；
- 持仓超过10日未走强。

## 七、进入系统前必须回测的参数

- 缩量阈值：20日均量的60%、70%、80%；
- 放量阈值：5日均量的1.1、1.2、1.5倍；
- 回调长度：2-5日；
- 周期风险窗口：5-10日；
- MA20跌破是否允许1日收复；
- 止损：1ATR、1.5ATR与固定百分比；
- 首档止盈：8%、10%、12%；
- 行业退出：跌出前3名后1、2、3日；
- 不同市场状态、行业类型和股票活跃度下分别统计。

回测必须计入涨跌停、停牌、手续费、滑点，避免未来函数和幸存者偏差。任何规则在样本外验证前，都只能作为研究信号，不能作为自动交易指令。
